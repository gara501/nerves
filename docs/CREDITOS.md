## Pantalla de inicio

El flujo es Boot → Preload → Intro → PLAY → Game. ABOUT muestra el logo, la autoría y enlaces a los packs; VOLVER o Escape cierra ABOUT. Se puede navegar con ratón, Tab, flechas y Enter/Espacio; mando: cruceta, A para aceptar y B para volver. Escape durante la partida vuelve a la intro. `?level=2` conserva la selección de nivel para PLAY. No hay ranking ni conexión a Supabase todavía.
